# DSH 会话分栏

为 **DeepSeek Harness Desktop 0.2.2-rc.5** 提供左右两个独立会话栏。将工作区中的会话拖到对话区左、右边缘即可分栏；两个输入框分别保留草稿。

这是独立社区插件，包含三个经过修改的 DSH 原生 UI 模块，不是 DeepSeek 官方发布。上游和打包依赖的许可证保留在 [LICENSE](<LICENSE>) 与 [第三方声明](<THIRD_PARTY_NOTICES.md>) 中。

## 功能

- 左右双栏，支持不同工作区的会话。
- 拖入已显示的会话时聚焦已有栏，不重复打开。
- 每栏独立输入、消息展示和滚动；长会话保留底部输入框。
- 拖动分隔线调整比例；窄窗临时显示聚焦栏，拉宽后恢复。
- 关闭一栏只收起视图，不删除会话或停止任务。
- 左侧导航作用于当前聚焦栏，栏位、焦点和比例在重载后恢复。
- 拖到中央取消操作，不替换会话，也不把会话 ID 写进输入框。

## 安装与升级

**本包替换核心会话界面模块，首次安装和升级都要整页冷加载。不要在旧页面上直接热切换这些模块。** 发布版的 `⌘R` 不提供重载菜单；macOS 红色关闭按钮只隐藏窗口。

1. 保存未发送的附件，并结束需要保留的运行中任务。
2. 在 DSH 中暂停客户端热更新插件 `include:client-hmr`，再安装本包。让 DSH 通过插件管理器安装下面的 release URL：
   ```text
   https://github.com/ZaneZhang-67/dsh-session-split/releases/download/v0.1.1/local-dsh-session-split-0.1.1.tgz
   ```
3. 保持旧 `@dsh-external/dsh-split-panes` 停用。本包会覆盖停用原生 `ui-session`、`ui-workspace`、`ui-conversation`，挂载随包提供的替代模块。没有旧分栏插件时，其可选覆盖项可能报告“目标不存在”；原生三个目标应存在。
4. **完全退出 DSH 并重新打开**。macOS 使用应用菜单“退出 DeepSeek Harness”或 `⌘Q`。
5. 确认会话正常显示后，恢复 `include:client-hmr` 原来的启用状态，再完全退出、重开一次，使新页面恢复热更新连接。

也可以下载 `.tgz` 后，让 DSH 的插件管理器安装它的本地文件路径。本包不含安装脚本，不会直接修改 app.asar 或 profile 配置文件。当前本地原型与本包沿用同一个包名 `@local/dsh-session-split`，便于原位升级。

## 使用

打开一个会话，再将工作区中的另一个**会话行**拖到对话区左侧或右侧约四分之一的区域；出现高亮后松手。最多显示两个会话。两栏已满时拖入第三个会话不会替换已有栏；先关闭一栏再拖入。

点击某一栏使其获得焦点，再点击侧栏会话即可切换这一栏。关闭按钮位于每栏右上角，中间分隔线可拖动；聚焦分隔线后也可用左右方向键调整。

## 兼容性与限制

- 安装版本锁定为 `0.2.2-rc.5`，不对其它 DSH 版本作兼容承诺。
- macOS Desktop 的双栏和输入框已由实际使用者确认恢复正常。分栏状态、草稿、拖拽、模块加载等另有自动化测试；Windows/Linux 的实际界面尚未验收。
- 附件草稿只在当前页面内保留；刷新或退出应用前需要自行处理未发送附件。
- 本包与其它替换相同会话 UI 槽位的插件不要同时启用。
- 卸载或停用也应按“暂停热更新 → 停用本包 → 完全退出重开 → 恢复热更新”的次序操作；原生模块随后恢复。
